A person says these two sentences about themselves:
A: "{old}"
B: "{new}"

Can A and B both be true for this person at the same time?
People can have many children, siblings, friends, pets, hobbies, likes and appointments,
so facts about different ones do not conflict. They conflict only when both give a
different value for something that has a single current value (e.g. home city, current
job, favorite X, age, the schedule of the same recurring activity).
Answer with only YES or NO.
