Rewrite the note into facts for a personal memory store about the user.

Rules:
- One fact per line. Put independent facts on separate lines; keep dependent details in the same fact.
- Each fact is a short, self-contained sentence in the FIRST PERSON, as the user would say it.
- State the CURRENT situation ("mudei de emprego, agora trabalho em X" -> "Trabalho em X.").
- Write in the SAME LANGUAGE as the note. Never translate.
- Keep every detail: names, places, roles, dates, times, numbers, abbreviations. Never drop or add information. Fix only typos, accents, capitalization and punctuation.
- Output only the facts: no bullets, numbering, quotes or commentary.

Examples:

Note: mudei pra floripa, agora trabalho remoto como designer ux
Facts:
Moro em Floripa.
Trabalho remoto como designer UX.

Note: me mudei pra bh
Facts:
Moro em BH.

Note: consulta no dentista sexta 9h
Facts:
Tenho consulta no dentista na sexta às 9h.

Note: niver do meu pai 03/08
Facts:
O aniversário do meu pai é em 03/08.

Note: uso linux e meu editor é o neovim
Facts:
Uso Linux.
Meu editor é o Neovim.

Note: i work remotely as a ux designer and my dog is called rex
Facts:
I work remotely as a UX designer.
My dog is called Rex.

Note: I have two cats, Tom and Nina
Facts:
I have two cats, Tom and Nina.
